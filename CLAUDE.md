# CLAUDE.md

## What this repo does

SAR building damage validation pipeline. Evaluates damage-probability rasters against
ground-truth building labels by sweeping probability thresholds, computing per-building
predictions via pixel/polygon area overlap, and reporting Accuracy / F1 / CSI (plus
Precision / Recall / FPR in the Turkiye variant).

---

## Scripts

| Script | Ground-truth source | Step 1 |
|---|---|---|
| `metrics_calc.py` | Damage point files spatially joined onto building footprints | Spatial join → GeoParquet |
| `metrics_calc_building_tky.py` | Per-building Turkish labels already in GeoPackage | Translate ACIKLAMA → binary |

Steps 2 (threshold sweep) and 3 (plotting) are the same logic in both scripts.
The Turkiye script adds overlap-table caching and windowed raster reads.

---

## Running

```bash
# Locally
python metrics_calc.py [--config config.yaml]
python metrics_calc_building_tky.py [--config config_building_tky.yaml]

# PBS cluster
qsub run_metrics.pbs
qsub run_metrics_tky.pbs
qsub -v CONFIG=alt_config.yaml run_metrics_tky.pbs   # override config at submit time
```

## Config structure

```
steps:     — booleans to enable/disable each step
step1:     — input files, column names, class-to-binary mapping
step2:     — raster list, threshold sweep params, area_frac_threshold, cache_dir
step3:     — out_dir, axis limits, color_map
```

**Dual-threshold logic** (core of the pipeline):
- Raster threshold `T` (swept): pixel is "damaged" if `raster_value >= T`
- `area_frac_threshold` (fixed): building is "Damaged" if `damaged_pixel_area / building_area >= area_frac_threshold`

When a step is disabled, the next step reads from an `input_*` override path in its own block.

## Key data dependencies

- `Turkiye/translations.py` — `grading_translate` dict (Turkish → English labels),
  loaded dynamically at runtime by `metrics_calc_building_tky.py`
- `Turkiye/validation/` — input GeoPackage with `ACIKLAMA` column
- `Turkiye/TD021/` — SAR damage probability rasters

`matplotlib`, `pyyaml`.

## Do not commit

- `Turkiye/validation_overlap*/` — cached pixel-overlap tables (large, regenerated by Step 2)
- `Turkiye/thresholded*/` — per-threshold GeoPackages (`save_per_threshold: true`)
- `*.parquet` and `*_Binary.gpkg` output files — derived data, regenerated by Step 1
- `threshold_sweep_metrics*.csv` — derived data, regenerated by Step 2
